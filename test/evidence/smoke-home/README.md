# Home page renders and is usable — evidence

> **Feature:** `LHD-001` · **Scenario:** `verify/scenarios/smoke-home.yml` · **Generated by:** `node verify/runner.mjs --only smoke-home` against `http://127.0.0.1:4113` on 2026-11-25

The first thing any visitor does: land on the home page, see the main content, and find the navigation.

## What changed for a reader

The home page no longer scrolls sideways. Before this fix the page was 12 pixels wider than the screen at every width (document width 1292 on a 1280 viewport and 402 on a 390 one), on this branch's parent and on the live site alike, so `smoke-home` failed its `no_horizontal_scroll` step. Three `row g-4` blocks in `index.md` sat directly inside sections with no container, and a Bootstrap row's negative side margins are only offset by a container's padding. The sections now sit in one `container-fluid`, as the sections of the theme's `news` layout do.

After the fix the document is exactly as wide as the viewport at 1280, 768 and 390 pixels, on the home page and on `/news/`, `/agencies/` and a Wargames level page (measured separately; the scenario covers the home page at two widths). The visible difference is 12 pixels of space on each side: the hero and the cards no longer touch the edge of the screen.
