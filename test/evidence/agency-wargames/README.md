## Not covered

- **Production.** These images come from the CI overlay build (`scripts/ci/build.sh`) served as static files on a local port. GitHub's own Pages build of the merged branch was not run; the overlay reproduces it in safe mode but is not it.
- **The other 216 pages.** The scenario opens three of the agency's 219 pages. The link check in the harness covers every page's internal links; nothing looked at each page's rendering.
- **Dark mode, search and the mobile drawers.** The colour-mode toggle, the search dialog and the off-canvas navigation were not exercised here.
