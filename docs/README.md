# lifehacker.dev documentation

> Every document in this repository, one line each — start with the root README, and see AGENTS.md for how to work here.

**Backlog of record:** GitHub Issues with the fleet labels. `_data/backlog.yml` is the autopilot's content queue, not the engineering backlog.

Start with [AUTOPILOT.md](AUTOPILOT.md) to operate the robot, [ARCHITECTURE.md](ARCHITECTURE.md) for how its loop fits together and [CICD.md](CICD.md) for the pipeline. Everything under `docs/` is excluded from the site build; the reader-facing docs are the `pages/_docs/` collection, published at <https://lifehacker.dev/docs/>.
